网络加速教程

下载 CC Switch、Claude Desktop 等软件时可能需要稳定访问海外网络。本教程用 FLClash + 机场，几步就能完成加速。

1

先了解：为什么要加速

部分软件的下载页（例如 CC Switch、FLClash 的 GitHub Release 页面，以及 Claude 官方下载页）在国内访问不稳定，可能导致网页加载失败或下载中断。开启网络加速后，这些请求会通过更稳定的线路完成。

两个概念： 机场服务商（如黑鹰云、星辰加速）提供分布在各地的网络节点，相当于「帮你出国访问的中转站」； FLClash 是加速工具（客户端），负责把你的网络请求接入机场的节点。FLClash 本身不提供节点，需要搭配机场的订阅地址一起使用。
2

注册机场并获取订阅

选一个机场注册账号并购买套餐即可。下面是本站也在使用的两家机场：

黑鹰云 星辰加速

注册并购买套餐后，在机场仪表盘按下面步骤拿到「订阅地址」：

  1. 登录机场仪表盘；
  2. 点击「一键订阅」；
  3. 点击「复制订阅地址」，复制得到一串 https://... 的订阅 URL。

订阅地址相当于机场节点的「钥匙」，只复制到自己的 FLClash 里使用即可。

3

安装 FLClash

FLClash 是一款免费开源的加速客户端，支持 Windows / macOS / Linux。到官方网站下载对应平台的安装包。

下载 FLClash

如果官方下载页访问不稳定，可以先借助手机热点或已有加速工具完成下载，或到官方 QQ 群咨询获取方式。

4

导入订阅配置

打开 FLClash，把刚才复制的订阅地址导入：

  1. 进入「配置」页面；
  2. 点击「＋」并选择「从 URL 获取配置」；
  3. 粘贴机场的订阅地址，保存。
导入后 FLClash 会自动下载机场的节点列表，通常几秒内完成。
5

选择节点并启动加速

  1. 进入「代理」页面，选择一个可用节点（延迟低的优先）；
  2. 进入「仪表盘」页面，点击右下角的三角形按钮启动加速；
  3. 按钮变为运行状态即表示加速已开启。
提示：如果开启后反而无法上网，说明当前节点不可用，回到「代理」页面换个节点试试。
6
