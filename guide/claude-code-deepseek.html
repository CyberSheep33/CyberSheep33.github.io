在 Claude Code 中使用 DeepSeek

通过 Sheep AI Plus 调用 DeepSeek 模型，在 Claude Code 终端里使用。DeepSeek 上游是 OpenAI Chat Completions 格式，需要借助 CC Switch 本地路由做格式转换。

1

安装 Node.js 与 Git

Claude Code 通过 npm 安装，需要先准备好 Node.js 与 Git 环境。如果还没安装，参考 Claude Code 教程 的 Step 1 完成即可。

查看环境准备步骤 →
2

安装 Claude Code

Claude Code 是 Anthropic 官方推出的终端 AI 编程工具。推荐使用官方安装脚本或 npm 安装。

npm install -g @anthropic-ai/claude-code

macOS / Linux 也可以使用官方一键安装脚本：

curl -fsSL https://claude.ai/install.sh | bash

安装完成后确认版本：

claude --version
3

安装 CC Switch

CC Switch 用于管理 AI Coding 工具的 API 配置。DeepSeek 与 Claude Code 协议不同，需要 CC Switch 的本地路由进行转换，所以必须先装好 CC Switch。

下载 CC Switch

注意：CC Switch 的下载链接会跳转到 GitHub，国内网络可能不稳定，建议先开启加速再下载。还没有加速方案？看 网络加速教程（FLClash + 机场）。

4

注册 Sheep AI Plus 并创建 API Key

  1. 登录 / 注册 Sheep AI Plus；
  2. 进入「API 令牌」页面；
  3. 点击「添加令牌」，输入令牌名称即可创建；
  4. 复制生成的密钥（通常以 sk- 开头）。
💡 建议选择 DeepSeek 分组

DeepSeek 模型在 Sheep AI Plus 有对应的分组与特价线路。创建令牌时手动选择 DeepSeek 分组，或参考分组指南选择最划算的组合，避免被智能路由分配到偏贵的线路。

查看分组选择指南 → 查看模型价格 →
前往 Sheep AI Plus →
5

在 CC Switch 中添加 DeepSeek 供应商

打开 CC Switch，切换到「Claude Code」面板，新建一个供应商并填写：

  1. 点击右上角「＋」新建供应商；
  2. 名称：DeepSeek；
  3. 接口地址：https://sheepaiplus.top/v1；
  4. API Key：粘贴刚才创建的密钥；
  5. 上游格式：OpenAI Chat Completions（DeepSeek 使用 OpenAI 兼容协议，必须选这个）；
  6. 默认模型：deepseek-v4-flash（快速、性价比高，日常首选）；需要更强推理时填 deepseek-v4-pro；
  7. 保存并点击「启用」。

为什么选 OpenAI Chat Completions？DeepSeek 的上游接口是 OpenAI Chat Completions 格式，而 Claude Code 需要 Anthropic Messages 格式。CC Switch 的本地路由会在中间做格式转换，所以供应商这里必须按上游真实格式填写。

6

开启本地路由

格式转换依赖 CC Switch 的本地路由，需要手动开启：

  1. 点击 CC Switch 左上角的齿轮进入设置；
  2. 进入「路由」页面；
  3. 在「本地路由」中打开路由总开关；
  4. 然后打开「Claude」路由开关（Claude Code 的请求会走本地网关做转换）。
⚠️ 别忘了这一步

不开启路由的话，Claude Code 会直接把 DeepSeek 的请求当 Anthropic 协议发出去，导致无法调用。开启总开关 + Claude 路由开关后即可正常使用。

7

启动并验证

配置完成后，在项目目录里启动 Claude Code，发送一个简单问题确认可以正常调用：

claude

在对话中输入类似：

请介绍一下你自己，并确认你现在通过 DeepSeek 在 Sheep AI Plus 上工作。

能正常返回结果，说明 DeepSeek 配置已生效 🐑。
