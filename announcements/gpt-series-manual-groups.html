GPT 系列使用建议 · 2026-08-31

GPT 系列推荐用法：手动分组 + $sol-luna

如果你会在 Sol、Terra、Luna 之间切换，建议关闭智能路由并手动选择分组。下面五个分组的当前倍率相对较低，而且三款模型都能使用，方便在不同任务之间复用同一套配置。

推荐配置方式

手动选择分组能让调用路径和预算更可控；配置前请确认你创建的 API Key 支持关闭智能路由。

01
创建 API Key在 Sheep AI Plus 创建密钥，确认准备使用 GPT 系列模型。
02
关闭智能路由将 Key 的分组策略从智能路由改为手动选择，避免平台在不同分组间自动切换。
03
选择一个公开分组并实测先从下面五个共同可用分组中选择，再根据任务质量、延迟和实际账单调整。

五个可复用的低倍率分组

这五个是 Luna 也可用的公开分组中，当前相对倍率最低的五个。它们不是整个 GPT 分组列表的绝对最低项，因为更低的 Codex 专属分组并不支持 Luna。

按任务选择模型

三款模型都支持上面五个分组。下面是依据平台当前模型描述整理的起步建议，不替代你的实际评测。

gpt-5.6-sol旗舰高端定位。复杂、质量优先或高影响任务可先从 Sol 评估；按预算从 Azure-Gpt-4 或 Azure-Gpt-5 开始试用。
gpt-5.6-terra算力与成本均衡定位。日常编程、分析和多步骤任务可作为默认候选；先试 Azure-Gpt-2、Azure-Gpt-3 或 Azure-Gpt-4。
gpt-5.6-luna低成本、大批量定位。适合先做批处理、整理和轻量任务；Azure-Gpt-2 与 Azure-Gpt-3 是较低倍率的起点。

需要让智能体按任务分工时

可选安装 codex-sol-luna 技能

如果任务包含复杂拆解、并行执行或需要把高难度工作与常规工作区分开，可以参考 yangphere/codex-sol-luna 的安装说明。给智能体分配任务时，在需求中明确写入下面这段内容，即可显式请求使用该技能的工作流。

$sol-luna

这种方式适合在任务复杂度不同的场景中主动选择执行策略，从而更好地平衡任务质量与调用成本；实际效果仍取决于任务、模型和可用渠道。
