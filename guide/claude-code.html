Claude Code 快速开始

从安装 Claude Code 到接入 Sheep AI Plus，按照下面步骤即可完成配置。

1

安装 Node.js 与 Git

Claude Code 通过 npm 安装，需要先准备好 Node.js（提供 npm）和 Git 环境。没有装过的话，先到官方页面下载安装。

下载 Node.js 安装 Git

Node.js 下载 LTS（长期支持）版本即可，安装时保持默认选项。Git 按官方安装说明装好即可，Windows 用户安装时建议勾选「Add to PATH」。

2

安装 Claude Code

Claude Code 是 Anthropic 官方推出的终端 AI 编程工具，支持在终端里完成代码编写、重构、测试与调试。推荐使用官方安装脚本或 npm 安装。

npm install -g @anthropic-ai/claude-code

macOS / Linux 也可以使用官方一键安装脚本：

curl -fsSL https://claude.ai/install.sh | bash

安装完成后，可以执行以下命令确认版本：

claude --version
查看官方安装说明
3

安装 CC Switch

CC Switch 用于管理 Codex、Claude Code 等 AI Coding 工具的 API 配置。它把繁琐的配置文件管理变成可视化切换，后续我们用它一键接入 Sheep AI Plus。

下载 CC Switch

注意：CC Switch 的下载链接会跳转到 GitHub，国内网络可能不稳定，建议先开启加速再下载。还没有加速方案？看 网络加速教程（FLClash + 机场）。

4

注册 Sheep AI Plus

Sheep AI Plus 是 CyberSheep 的聚合 API 平台，一个 Key 调用全球主流模型，兼容 OpenAI SDK。还没有账号的话，先去注册一个。

前往 Sheep AI Plus →
5

创建 API Key

  1. 登录 Sheep AI Plus；
  2. 进入「API 令牌」页面；
  3. 点击「添加令牌」，输入令牌名称即可创建；
  4. 复制生成的密钥（通常以 sk- 开头）。
💡 选对分组，价格可能差好几倍

创建令牌时默认「智能路由」会自动选择分组（偏向稳定、偏贵）；手动选择合适分组会便宜很多，这也是 Sheep AI Plus 最划算的用法。

查看分组选择指南 →

API Key 只在下方配置时使用，请妥善保管，不要分享给他人。

6

一键导入 CC Switch

把刚创建的 API Key 粘贴到下面，点击「一键导入 CC Switch」，确认弹窗后即完成配置。

7

启动并验证

配置导入后，在项目目录里启动 Claude Code，发送一个简单问题确认可以正常调用：

claude

在对话中输入类似：

请介绍一下你自己，并确认你正在通过 Sheep AI Plus 工作。

能正常返回结果，说明 Sheep AI Plus 配置已生效，开始使用吧 🐑。
