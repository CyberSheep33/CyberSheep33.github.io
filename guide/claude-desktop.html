Claude Desktop 快速开始

从安装 Claude 桌面客户端到接入 Sheep AI Plus，按照下面步骤即可完成配置。

1

安装 Claude Desktop

Claude Desktop 是 Anthropic 官方推出的桌面客户端。到 Claude 官方下载页面获取对应平台的安装包。

下载 Claude Desktop

注意：国内访问 Claude 官方下载页可能加载失败，建议开启加速后再下载。还没有加速方案？看 网络加速教程（FLClash + 机场）。

2

安装 CC Switch

CC Switch 用于管理 Codex、Claude Code 等 AI Coding 工具的 API 配置。它把繁琐的配置文件管理变成可视化切换，后续我们用它一键接入 Sheep AI Plus。

下载 CC Switch

注意：CC Switch 的下载链接会跳转到 GitHub，国内网络可能不稳定，建议先开启加速再下载。还没有加速方案？看 网络加速教程（FLClash + 机场）。

3

注册 Sheep AI Plus

Sheep AI Plus 是 CyberSheep 的聚合 API 平台，一个 Key 调用全球主流模型，兼容 OpenAI SDK。还没有账号的话，先去注册一个。

前往 Sheep AI Plus →
4

创建 API Key

  1. 登录 Sheep AI Plus；
  2. 进入「API 令牌」页面；
  3. 点击「添加令牌」，输入令牌名称即可创建；
  4. 复制生成的密钥（通常以 sk- 开头）。
💡 选对分组，价格可能差好几倍

创建令牌时默认「智能路由」会自动选择分组（偏向稳定、偏贵）；手动选择合适分组会便宜很多，这也是 Sheep AI Plus 最划算的用法。

查看分组选择指南 →

API Key 只在下方配置时使用，请妥善保管，不要分享给他人。

5

一键导入 CC Switch

把刚创建的 API Key 粘贴到下面，点击「一键导入 CC Switch」，确认弹窗后即完成配置。

说明：CC Switch 的 Claude 配置面向 Claude 产品线（Claude Code 与桌面客户端）。桌面客户端对导入配置的兼容程度以官方客户端实际支持为准，若导入后未生效，请参考官方文档手动配置。

6

启动并验证

配置导入后，打开 Claude Desktop，发送一个简单问题确认可以正常调用。

  1. 打开 Claude Desktop；
  2. 选择 Sheep AI Plus 供应商；
  3. 发送一个简单问题，例如「你好，请介绍一下你自己」；
  4. 确认可以正常返回结果。

能正常返回结果，说明 Sheep AI Plus 配置已生效，开始使用吧 🐑。
