sheepai-creator 桌面应用上线

2026-07-24

赛博小羊又一款开源作品 —— sheepai-creator 桌面应用正式上线。

sheepai-creator 是一款跨平台的 Electron 桌面应用，通过可配置的 AI API 服务创建与编辑图像、视频，适合内容创作者把生成式 AI 能力直接放进日常工具链。

  • 跨平台 —— Windows / macOS / Linux；
  • 可配置 API —— 接入自有的 AI API 服务，灵活组合图像与视频模型；
  • 开源 —— 源码托管在 SheepAI-Lab 组织。

代码已开源，欢迎 Star、反馈与贡献：github.com/SheepAI-Lab/sheepai-creator
