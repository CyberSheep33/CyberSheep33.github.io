在 Codex 中使用 DeepSeek

通过 Sheep AI Plus 调用 DeepSeek 模型，在 Codex 终端里使用。DeepSeek 上游是 OpenAI Chat Completions 格式，需要借助 CC Switch 本地路由完成协议适配。

1

安装 Node.js 与 Git

Codex CLI 通过 npm 安装，需要先准备好 Node.js 与 Git 环境。如果还没安装，参考 Codex CLI 教程 的 Step 1 完成即可。

查看环境准备步骤 →
2

安装 Codex CLI

Codex CLI 是 OpenAI 官方推出的终端 AI 编程工具。推荐使用 npm 安装，Windows / macOS / Linux 通用。

npm install -g @openai/codex

安装完成后确认版本：

codex --version
3

安装 CC Switch

CC Switch 用于管理 AI Coding 工具的 API 配置。DeepSeek 需要通过 CC Switch 的本地路由接入 Codex，所以必须先装好 CC Switch。

下载 CC Switch

注意：CC Switch 的下载链接会跳转到 GitHub，国内网络可能不稳定，建议先开启加速再下载。还没有加速方案？看 网络加速教程（FLClash + 机场）。

4

注册 Sheep AI Plus 并创建 API Key

  1. 登录 / 注册 Sheep AI Plus；
  2. 进入「API 令牌」页面；
  3. 点击「添加令牌」，输入令牌名称即可创建；
  4. 复制生成的密钥（通常以 sk- 开头）。
💡 建议选择 DeepSeek 分组

DeepSeek 模型在 Sheep AI Plus 有三个推荐分组：Self-Deployed-2（最便宜）、Self-Deployed-3（其次）、deepseek-1（最稳定）。追求极致预算选 Self-Deployed-2，追求稳定选 deepseek-1；创建令牌时手动选择对应分组即可。

查看分组选择指南 → 查看模型价格 →
前往 Sheep AI Plus →
5

在 CC Switch 中添加 DeepSeek 供应商

打开 CC Switch，切换到「Codex」面板，新建一个供应商并填写：

  1. 点击右上角「＋」新建供应商；
  2. 名称：DeepSeek；
  3. 接口地址：https://sheepaiplus.top/v1；
  4. API Key：粘贴刚才创建的密钥；
  5. 上游格式：OpenAI Chat Completions（DeepSeek 使用 OpenAI 兼容协议，必须选这个）；
  6. 默认模型：deepseek-v4-flash（快速、性价比高，日常首选）；需要更强推理时填 deepseek-v4-pro；
  7. 保存并点击「启用」。

为什么选 OpenAI Chat Completions？DeepSeek 的上游接口是 OpenAI Chat Completions 格式。Codex 默认走 OpenAI Responses 协议，CC Switch 的本地路由会在中间把 Chat Completions 适配给 Codex 使用。

6

开启本地路由

协议适配依赖 CC Switch 的本地路由，需要手动开启：

  1. 点击 CC Switch 左上角的齿轮进入设置；
  2. 进入「路由」页面；
  3. 在「本地路由」中打开路由总开关；
  4. 然后打开「Codex」路由开关（Codex 的请求会走本地网关做协议适配）。
⚠️ 别忘了这一步

不开启路由的话，Codex 无法正确调用 DeepSeek 的 Chat Completions 上游。开启总开关 + Codex 路由开关后即可正常使用。

7

启动并验证

配置完成后，打开终端启动 Codex，发送一个简单问题确认可以正常调用：

codex

进入对话后，发送一个测试问题：

codex "用 Python 写一个快速排序"

能正常返回结果，说明 DeepSeek 配置已生效 🐑。
